### 1. 元数据缓存验证

**测试目标**: 验证缓存时长已更新为 30 天

```bash
# 清除所有缓存
curl -X DELETE http://127.0.0.1:8000/api/llm/cache

# 获取 deepseek 元数据
curl -s "http://127.0.0.1:8000/api/llm/providers/deepseek/metadata" | python3 -c "
import json, sys
data = json.load(sys.stdin)
print('✓ 元数据获取成功')
print(f'  提供商: {data[\"data\"][\"name\"]}')
print(f'  Base URL: {data[\"data\"][\"base_url\"]}')
"

# 查看缓存统计
curl -s http://127.0.0.1:8000/api/llm/cache/stats | python3 -c "
import json, sys
data = json.load(sys.stdin)
print('\n缓存统计:')
for provider, stats in data.items():
    if stats['metadata_cached']:
        print(f'  ✓ {provider}: 已缓存')
"
```

**预期结果**: ✅ 缓存将保持 30 天

## 🐛 已知问题排查

### 问题 1: Base URL 未自动填充

**检查**:
1. 打开浏览器控制台（F12）
2. 查看 Network 标签
3. 检查 `/api/llm/providers/{id}/metadata` 请求
4. 确认返回 `base_url` 字段

**解决**:
- 刷新元数据: 切换到"元数据管理"，点击"刷新所有"
- 清除缓存: 点击"清除所有缓存"

### 问题 2: 模型列表为空

**检查**:
1. 查看 API 响应
2. 确认 `models` 字段存在且为对象

**解决**:
- 刷新元数据
- 检查后端日志: `tail -f logs/backend.log`

### 问题 3: 选择模型后参数未更新

**检查**:
1. 打开浏览器控制台
2. 查看是否有 JavaScript 错误

**解决**:
- 刷新页面
- 清除浏览器缓存
