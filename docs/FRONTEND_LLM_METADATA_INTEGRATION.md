## 🚀 使用指南

### 访问页面

1. 启动服务：
   ```bash
   ./dev.sh start
   ```

2. 访问前端：

- 查看模型 ID、描述、上下文窗口、最大输出等信息

## 🎯 技术实现

### 数据流

```
前端组件
    ↓
React Query Hooks (自动缓存)
    ↓
API 层 (fetch)
    ↓
后端 API (http://127.0.0.1:8000/api/llm/*)
    ↓
Python 后端 (24小时缓存)
    ↓
外部 API (llm-metadata)
```

### 缓存策略

#### 前端缓存（React Query）
- **staleTime**: 1 小时
- 数据在 1 小时内不会重新请求
- 刷新操作会强制更新缓存

#### 后端缓存（Redis/内存）
- **TTL**: 24 小时
- 自动过期
- 可手动清除

### 状态管理

使用 React Query 进行状态管理：
- 自动处理 loading、error、success 状态
- 自动缓存和重新验证
- 乐观更新
- 自动重试

## 📋 API 端点映射

| 前端功能 | API 端点 | 方法 |
|---------|---------|------|
| 获取提供商列表 | `/api/llm/providers` | GET |
| 获取元数据 | `/api/llm/providers/{id}/metadata` | GET |
| 获取模型列表 | `/api/llm/providers/{id}/models` | GET |
| 刷新元数据 | `/api/llm/providers/{id}/refresh` | POST |
| 刷新所有 | `/api/llm/providers/refresh-all` | POST |
| 清除缓存 | `/api/llm/providers/{id}/cache` | DELETE |
| 清除所有缓存 | `/api/llm/cache` | DELETE |
| 缓存统计 | `/api/llm/cache/stats` | GET |

## 🔍 调试提示

### 检查 API 调用

打开浏览器开发者工具 → Network 标签：
- 筛选：`llm`
- 查看请求/响应

### 检查缓存状态

React Query DevTools（如果安装）：
- 查看 `['llm', 'metadata', providerId]` 查询
- 查看 `['llm', 'cache', 'stats']` 查询

### 常见问题

#### 1. API 404 错误
**问题**：使用 `localhost:8000` 访问失败  
**解决**：后端使用 `127.0.0.1:8000`，确保前端 API 配置正确

#### 2. 数据不刷新
**问题**：刷新后数据没有更新  
**解决**：检查 React Query 缓存是否正确失效（invalidateQueries）

#### 3. 模型列表为空
**问题**：点击"查看模型列表"显示为空  
**解决**：检查元数据格式，可能是 `models` 字段为数组或对象
