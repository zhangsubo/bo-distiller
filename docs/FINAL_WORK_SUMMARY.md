## 🎯 技术亮点

### 1. 智能表单设计
```typescript
// 只在字段为空时设置默认值
if (!currentValues.api_base) {
  form.setFieldValue(['providers', providerId, 'api_base'], metadata.base_url);
}
```
- 首次加载自动填充
- 用户修改不被覆盖
- 智能默认值策略

### 2. 响应式更新
```typescript
// 选择模型时自动更新参数
const handleModelChange = (modelId: string) => {
  const model = metadata.models[modelId];
  form.setFieldValue(['providers', providerId, 'max_context'], model.limit.context);
  form.setFieldValue(['providers', providerId, 'max_output'], model.limit.output);
};
```
- 实时响应用户操作
- 确保参数一致性

### 3. 双层缓存策略
```
前端: React Query (1 小时)
    ↓
后端: Storage (30 天)
    ↓
外部: models.dev API
```
- 最优性能
- 最小请求
- 数据新鲜度平衡

## 🔍 关键决策

### 决策 1: 缓存时长 30 天

**理由**:
- 模型元数据变化频率低（月度级别）
- 减少外部 API 依赖
- 提升系统稳定性

**风险**: 新模型上线后不能立即看到  
**缓解**: 提供手动刷新功能

### 决策 2: 保留本地覆盖机制

**理由**:
- 上游数据可能有错误（如 minimax）
- 快速修正关键错误
- 不依赖上游修复

**实现**: `BASE_URL_OVERRIDES` 字典

### 决策 3: 模型下拉而非输入

**理由**:
- 避免拼写错误
- 提供完整信息
- 引导正确选择

**权衡**: 失去输入自定义模型的灵活性  
**解决**: 如需自定义，可手动修改保存的配置
